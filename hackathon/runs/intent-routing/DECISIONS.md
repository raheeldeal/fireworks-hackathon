- **Data source:** PolyAI-LDN/task-specific-datasets `banking_data` CSVs on GitHub (identical content to HF `PolyAI/banking77`, CC-BY-4.0). Chosen because `datasets` is not installed and the raw CSVs need no library.
- **Test set:** 2 utterances per intent from the *official test split* = 154 rows, seed 20261101, order shuffled, locked and chmod 444. Hash 3547e8f9bc1491ce…
- **Train/few-shot pool:** 4 per intent from the official train split = 308 rows, zero overlap (check_leak.py).
- **Label definitions:** 77 one-line definitions written by hand (labels.json), checked to match the dataset's categories.json exactly.
- **Reasoning:** all six models think by default on this prompt. nemotron spends ~1,100 reasoning tokens per row and gets cut off at max_tokens 1024 (empty content → invalid), so max_tokens is 4096 everywhere. `reasoning_effort="none"` works on nemotron, deepseek-flash, kimi-k3; GLM models need `"low"` (which stops thinking) and gpt-oss accepts `"low"` only. Baseline = model default (no reasoning param). "no-think" is treated as a harness intervention on the small models.
- **Probe cost:** 16 one-row probe calls were made before ledgering existed; cost estimated by hand ($0.0305) and appended to ledger.csv as one row.
- **Routing simulation:** small model answers on all 154 rows with a self-reported confidence; the escalation model's predictions on the same rows come from its own full-set run. Routing accuracy/cost per threshold is computed offline from those two files (no extra API calls). This is exact, not approximate, because temperature is 0 and the escalation call would be identical to the one already made.
- **kimi-k3:** 100 rows max (protocol). The first 100 rows of the shuffled locked set. All other models are also reported on that same 100-row subset for a like-for-like frontier comparison.
